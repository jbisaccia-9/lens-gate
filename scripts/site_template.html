lens-gate puts an AI assistant on a self-hosted Metabase. Every query, chart and dashboard edit runs as the person who asked, and the answer is shown only if it passes six checks. Pick someone at Larkmoor Goods, a fictional 12-store retailer, and ask what they'd ask.

This page replays a real run of the repo's code: every answer, refusal and number below was produced by the broker and graded by the gate when the page was built. Nothing here is live or typed by hand. See the code on GitHub.
